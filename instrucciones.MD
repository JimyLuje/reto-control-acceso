# Instrucciones para la IA

### Estos fueron los mensajes que le dimos a la Inteligencia Artificial para hacer el proyecto:

## Paso 1: Pedir los pasos
Le dijimos:
> "Ayúdanos con un paso a paso para hacer un programa en Java de control de acceso a un evento. Reglas: solo mayores de edad (>=18), usar arreglos normales con límite de espacio (sin ArrayList), cobrar entrada y mostrar la lista de ingresados y el total recaudado usando Maven y clases."

## Paso 2: Pedir los códigos
Le dijimos:
> "Genéranos los códigos de las 3 clases en el paquete puce.edu.ec:
> 1. Asistente (nombre y edad).
> 2. Evento (controla el arreglo, aforo, edades y dinero).
> 3. Main (menú en consola para registrar y ver el resumen)."
